# ヤミソコ / Yamisoko — 設計仕様書

- 日付：2026-11-06
- 状態：レビュー待ち

## 0. 目的と成功の目安

- **目的**：できるだけ多くの人に遊んでもらう Web ゲームを作り、公開し、アップデートを続ける。
- **成功の目安**：SNS で URL やスコアが共有され、遊んだ人が何度も戻ってくること。ゲーム名「ヤミソコ / Yamisoko」で検索すると表示されること。

## 1. ゲーム概要

暗い地下フロアを、進む方向を照らすライトを頼りに探索し、出口（下り階段）を見つけてどんどん下へ降りていく短時間アクション。ゲームオーバー後は集めたコインで強化して再挑戦する（アクション＋育成のミックス）。

- 1 プレイの目安：1〜3 分
- スコア：到達した一番深い階（例：「地下 12 階まで到達」）

## 2. ゲームのルール

### 2.1 フロア
- 各フロアはランダム生成の迷路。スタートから出口まで必ず到達できる。
- 迷路生成は乱数の種（シード）を受け取り、同じシードなら同じ迷路になる。
- 深い階ほど迷路が広くなる（10 階ごとに一段階広げる）。

### 2.2 ライト
- 向いている方向（＝最後に移動した方向）に扇形の光を出す。
- それとは別に、プレイヤーの足元を小さな円で常に照らす。
- 強化で「光の距離」「光の角度」が伸びる。

### 2.3 電池
- 時間経過で減る。0 になったらゲームオーバー。
- フロアに落ちている電池を拾うと回復（最大量は超えない）。
- 出口に到達すると少し回復する。

### 2.4 敵
- 暗闇をうろつき、プレイヤーが一定距離以内に入ると追いかける。
- 扇形の光（足元の円は含まない）の中にいる間は動かない。
- プレイヤーに触れるとゲームオーバー。シールドがあれば 1 回消費して耐え、短い無敵時間が入る。
- 深い階ほど数が増え、少し速くなる。

### 2.5 罠
- トゲ床。光（扇形または足元の円）で照らされた場所だけ見える。
- 踏むと電池が大きく減る（ゲームオーバーにはしない）。同じ罠はその後無効になる。
- 1 フロアあたりの数は少なめ。

### 2.6 コインと強化
- コインはフロアに落ちているもの＋到達階に応じたボーナス（ゲームオーバー時に加算）。
- 強化項目：光の距離／光の角度／電池の最大量／移動の速さ／シールド（開始時の枚数）。
- 各項目にレベルがあり、レベルが上がるほど値段が上がる。最大レベルあり。
- コイン・強化レベル・自己ベストはブラウザに保存し、次回も残る。

### 2.7 画面の流れ
タイトル → プレイ → ゲームオーバー（到達階・獲得コイン・シェアボタン）→ 強化画面 → プレイ

### 2.8 数値
電池の減る速さ、敵の速さ・数、罠の数、強化の値段と効果などはすべて `balance.ts` に集める。具体値は実装中に実際に遊んで決める。

## 3. 操作

- PC：矢印キーまたは WASD で移動。
- スマホ：画面上のバーチャルスティックで移動。
- ライトの向きは移動方向に自動で追従する（操作は移動のみ）。
- ゲーム中はページがスクロール・拡大しないようにする。

## 4. 見た目

- キャラ・敵・アイテムはシンプルな図形。光のぼかし・影・ちらつきの演出で雰囲気を出す。
- サイト全体も暗い配色でゲームとそろえる。

## 5. サイトのレイアウト

### 5.1 PC（横長）
- 上部：ゲーム名、言語切り替え（日本語 / EN）
- 中央：ゲーム画面（正方形）
- 左欄：お知らせ（最新アプデ）／遊び方／自己ベスト（最深階・プレイ回数）
- 右欄：変更ログ（過去分はスクロール）／今後の予定／シェアボタン／ご意見（Google フォームへのリンク）

### 5.2 スマホ（縦長）
- 上部：ゲーム名、言語切り替え
- その下：ゲーム画面（幅いっぱいの正方形）
- その下：タブ（お知らせ／遊び方／変更ログ／予定）で内容を切り替え。シェア・ご意見・自己ベストも下部に表示。

### 5.3 更新情報のデータ
`content/updates.json` に書き足すだけで、お知らせ・変更ログ・今後の予定が表示される。各項目は日付・バージョン・種類（お知らせ／変更／予定）・日本語文・英語文を持つ。書き方が間違っていればテストで検出する。

```json
{
  "date": "2026-11-20",
  "version": "1.1.0",
  "type": "change",
  "ja": "新しい敵「影」を追加しました",
  "en": "Added a new enemy: Shadow"
}
```

## 6. 言語

- 日本語と英語。切り替えボタンで変更し、選んだ言語はブラウザに保存する。
- 初回はブラウザの言語設定が日本語なら日本語、それ以外は英語。
- 画面の文章は `i18n/ja.json`・`i18n/en.json` に置く。

## 7. プログラムの構成

技術：TypeScript ＋ Vite、描画は Canvas 2D、テストは Vitest。

```
src/
├─ game/      ルールのみ（描画しない）
│   ├─ maze.ts      シード付き迷路生成
│   ├─ light.ts     扇形・円の照射判定
│   ├─ enemy.ts     うろつく・追う・光で止まる
│   ├─ player.ts    移動・電池・シールド
│   ├─ floor.ts     1 フロアの配置と進行
│   ├─ upgrades.ts  強化の種類・値段・効果
│   └─ balance.ts   数値設定
├─ render/renderer.ts   暗闇・光・図形の描画
├─ input/input.ts       キーボードとバーチャルスティック
├─ save/storage.ts      保存（使えない環境でも動作継続）
├─ site/panels.ts       左右の欄・スマホのタブ
├─ site/share.ts        X でのシェア
├─ i18n/ja.json, en.json
└─ main.ts              全体をつなぐ
content/updates.json    更新情報
```

- `game/` はブラウザの機能に依存せず、自動テストできる形にする。
- 保存処理は読み書きの失敗を握りつぶし、保存できなくてもゲームは遊べる。

## 8. シェアと検索対策

- ゲームオーバー画面と右欄に「X でシェア」ボタン。文面例：「ヤミソコで地下 12 階まで到達！ #ヤミソコ」＋ URL（英語版は英文）。
- ページのタイトル・説明文を日本語・英語で用意。
- SNS で共有したときに表示される画像（OGP）を用意。
- 公開後、Google Search Console への登録手順をオーナーに案内する。

## 9. テスト

- 自動テスト（Vitest）
  - 迷路：スタートから出口へ必ず到達できる／同じシードで同じ迷路
  - ライト：扇形内の敵だけ止まる、足元の円では止まらない
  - 電池：0 でゲームオーバー、罠で減る、拾うと回復し最大量を超えない
  - 敵：触れるとゲームオーバー、シールドがあれば 1 回耐える
  - 強化：値段・効果・最大レベル、コイン不足では買えない
  - 保存：保存できない環境でもエラーで止まらない
  - updates.json：形式チェック
- ブラウザでの確認：PC サイズとスマホサイズで表示と操作を確かめる。
- 最後にオーナーが実際に遊んで数値を調整する。

## 10. 公開

- GitHub リポジトリ `yamisoko` を作り、GitHub Pages で公開する。
- GitHub に変更を上げると、GitHub Actions がテスト → ビルド → 公開を自動で行う。テスト失敗時は公開しない。
- URL：`<GitHubユーザー名>.github.io/yamisoko`
