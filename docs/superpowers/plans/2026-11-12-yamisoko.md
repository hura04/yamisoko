# ヤミソコ / Yamisoko Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 暗闇をライトで照らして地下へ降りていく Web アクションゲーム「ヤミソコ」と、左右に更新情報を載せたサイトを作り、GitHub Pages で自動公開できる状態にする。

**Architecture:** `src/game/` は DOM に依存しない純粋なルール層（迷路・光・プレイヤー・敵・フロア・ラン・強化）で、Vitest で全てテストする。`render/`・`input/`・`site/`・`save/` がブラウザ側の薄い層で、`main.ts` がゲームループと画面遷移をつなぐ。更新情報は `content/updates.json` から表示する。

**Tech Stack:** TypeScript 5, Vite 5, Vitest 2, Canvas 2D, GitHub Actions + GitHub Pages, Playwright（プリインストール済み、ブラウザ確認用）

**Spec:** `docs/superpowers/specs/2026-11-06-yamisoko-design.md`

## Global Constraints

- ゲーム名：日本語「ヤミソコ」、英語「Yamisoko」。ハッシュタグ `#ヤミソコ` / `#Yamisoko`
- 言語は日本語と英語のみ。初回はブラウザ言語が `ja` で始まれば日本語、それ以外は英語。選択はブラウザに保存
- ゲーム画面は正方形。操作は移動のみ（矢印キー / WASD / バーチャルスティック）、ライトは移動方向に追従
- スコアは到達した一番深い階（地下 1 階から開始）
- 罠は踏んでもゲームオーバーにならず電池が減る。一度踏んだ罠は無効
- 敵は扇形の光の中だけで停止する（足元の円では停止しない）
- 保存（localStorage）が使えなくてもゲームは遊べる
- 数値は全て `src/game/balance.ts` に置く
- Vite の `base` は `/yamisoko/`
- 外部ランタイム依存なし（dependencies は空、devDependencies のみ）

## Review Focus

1. タブを裏に回して戻ったときの巨大な `dt` → 1 フレームの `dt` は `MAX_DT = 0.1` 秒で打ち切り、`visibilitychange` で一時停止（Task 11）
2. 壊れた／古い形式の保存データ → 既定値とマージして読み込み、例外を出さない（Task 7）
3. 斜め移動が速くなる・壁の角で引っかかる → 方向は正規化、衝突は x と y を別々に解決して壁沿いに滑る（Task 4, Task 10）
4. 敵や罠がスタート地点の真横に出る → スタートから一定距離以上離して配置（Task 8）
5. ゲーム中の矢印キー／スワイプでページがスクロール・拡大する → ゲーム領域で `preventDefault`、`touch-action: none`（Task 10, Task 11）

### Task 3: 光の判定

**Files:**
- Create: `src/game/light.ts`
- Test: `tests/game/light.test.ts`

**Interfaces:**
- Consumes: `Maze`, `Vec`, `isWall`, `BALANCE.light`
- Produces:
  - `hasLineOfSight(maze: Maze, a: Vec, b: Vec): boolean` — a→b を 0.1 タイル刻みでサンプルし、壁タイルを通れば false
  - `inBeam(maze: Maze, origin: Vec, facing: number, range: number, halfAngle: number, p: Vec): boolean` — 距離 ≤ range、角度差（-π〜π に正規化した絶対値）≤ halfAngle、かつ視線あり
  - `inAura(maze: Maze, origin: Vec, p: Vec): boolean` — 距離 ≤ `auraRadius` かつ視線あり
  - `isLit(maze, origin, facing, range, halfAngle, p): boolean` = `inBeam || inAura`

### Task 4: プレイヤー

**Files:**
- Create: `src/game/player.ts`
- Test: `tests/game/player.test.ts`

**Interfaces:**
- Consumes: `Maze`, `Player`, `PlayerStats`, `Vec`, `isWall`, `BALANCE.player`
- Produces:
  - `createPlayer(start: Vec, stats: PlayerStats, battery?: number, shields?: number): Player` — pos はタイル中心、facing 0、battery 省略時は `stats.maxBattery`、shields 省略時は `stats.shields`
  - `normalizeDir(dir: Vec): Vec` — 長さ 0 ならそのまま、長さ > 1 なら 1 に正規化
  - `movePlayer(maze: Maze, p: Player, dir: Vec, speed: number, dt: number): void` — `normalizeDir` 後に x 移動→衝突解決、y 移動→衝突解決（半径 `player.radius` の円と壁タイルの重なりを押し戻す）。dir が 0 でなければ `facing = atan2(dir.y, dir.x)`
  - `drainBattery(p: Player, dt: number): void`（0 未満にしない）
  - `addBattery(p: Player, amount: number, max: number): void`（max で頭打ち、0 未満にしない）
  - `hitPlayer(p: Player): 'shield' | 'dead' | 'ignored'` — `invulnTimer > 0` なら ignored、shields > 0 なら 1 減らして `invulnTimer = invulnSec`、それ以外 dead
  - `tickPlayer(p: Player, dt: number): void`（invulnTimer を減らす）

- [ ] **Step 1: 失敗するテストを書く** `tests/game/player.test.ts`（Task 3 と同じ `openMaze` をテスト共通ヘルパー `tests/helpers/maze.ts` に移す）
  - `diagonal not faster`：dir (1,1) で 0.1 秒動かした移動距離 ≈ speed*0.1（誤差 1e-6）
  - `stops at wall`：右へ 10 秒進めても `pos.x <= width-1-radius + 1e-6`
  - `slides along wall`：壁に右から押し付けつつ dir (1,1) で y が増える
  - `facing follows dir`：dir (0,-1) → facing ≈ -π/2、dir (0,0) なら facing 変化なし
  - `battery drain floors at 0`：battery 1 で 10 秒 → 0
  - `addBattery caps at max`
  - `shield absorbs one hit`：shields 1 → `hitPlayer` は 'shield'、直後は 'ignored'、invuln 経過後は 'dead'

### Task 8: フロア

**Files:**
- Create: `src/game/floor.ts`
- Test: `tests/game/floor.test.ts`

**Interfaces:**
- Consumes: Task 1〜5 の全て、`BALANCE`
- Produces:
  - `createFloor(depth: number, rng: Rng, stats: PlayerStats, carry?: { battery: number; shields: number }): FloorState`
    - 迷路は `generateMaze(cellsForDepth(depth), rng)`
    - 配置はセルタイルの中心から重複なしで選ぶ。start・exit には置かない
    - 敵 `count.enemies(depth)` 体：start との BFS 距離 ≥ `enemy.minSpawnDist`（候補不足なら最遠の候補から）
    - 罠 `count.traps(depth)` 個：start との BFS 距離 ≥ `trap.minSpawnDist`
    - コイン `floor.coins`、電池 `floor.batteries`
  - `stepFloor(s: FloorState, dir: Vec, stats: PlayerStats, dt: number, rng: Rng): FloorEvent[]` — status が 'playing' 以外なら空配列。順序：
    1. `dt = min(dt, BALANCE.maxDt)`、`tickPlayer`、`movePlayer`、`drainBattery`
    2. 未取得アイテムと距離 ≤ `pickupRadius` → 取得（coin は coinsCollected+1、battery は `addBattery(…, pickups.battery, stats.maxBattery)`）
    3. 未発動の罠と同じタイル → triggered、`battery -= trapDamage`（0 で止める）、'trap'
    4. 敵ごとに `frozen = inBeam(...)`、`stepEnemy`、`touchesPlayer` なら `hitPlayer` → 'shield' または dead（deathCause 'enemy'）
    5. battery が 0 → dead（deathCause 'battery'）
    6. プレイヤーのタイルが exit → status 'cleared'、`addBattery(exitRestore)`、'cleared'
  - `tileOf(p: Vec): Vec`（floor）
